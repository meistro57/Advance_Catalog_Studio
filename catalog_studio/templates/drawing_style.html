📖 Reading a dimension request

In the Drawing Style Manager a dimension strategy is the list of chains one view draws, and each chain is a dimension request. A request answers three questions. This editor shows them in the same order on every chain card.

  1. What does it measure? A list of point selection rules. Each rule picks objects (an object set such as Beams or Holes) and which of their points count: holes, system line, overall size, outline, cut features, center, attached parts, and so on.
  2. Which way does it run? The chain direction: along the view, along the main part, along an object, or one of the internal bolt/hole directions. Any of them can be reversed (negative).
  3. Where does it go? The "Arrangement on the drawing" switches: above or below, how much geometry it must stay clear of, and whether found objects share one chain or get one each.
"As reference" points

A point rule marked as reference only adds points when the chain already has something else to measure. Example from the guide: Holes - All plus Main Part - Extreme as reference dimensions the holes back to the ends of the part, and if the part has no holes, no chain is drawn at all.

The three-letter name code

Request names usually end in a code that spells out the arrangement switches, e.g. Mp X - Extreme GTA: overall size of the main part, kept clear of the whole detail, on top, all in one chain. The cards check the code against the stored switches and flag any mismatch — the switches are what Advance Steel uses.

Point types you'll see in rule names
Extreme / Size
The outer extreme points in the chain direction — overall length or width.
System
The object's system (work) line points, not its faces.
Holes
Hole centers.
Contour
Outline points, including those made by shortenings and notches.
Features
Points of finite cuts, such as rectangular contour processings.
Center
The object's center point.
Attaching parts
Where attached parts sit on the object.
Beam end processing
Beam-end contour points, including finite cuts at the end.
Bended beam inside/outside
The inside or outside face of a bent beam.
Collision / Development / Template / Stencil
Main-part collision points, bend development lines, template reference point, stencil points.
What the tags mean
  • {{ basis('guide') }} the meaning comes from Autodesk's Drawing Style Manager guide; for the switches, the column is matched to the DSM option by name and checked against the name code.
  • {{ basis('data') }} read straight from the stored row.
  • {{ basis('name') }} read from a rule's name. Names say what the author intended; the point type itself is stored as a number this file can't label.
  • {{ basis('raw') }} an Advance Steel number whose label lives in its built-in database, which an export doesn't include.
