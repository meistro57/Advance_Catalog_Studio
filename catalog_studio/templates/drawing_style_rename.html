Advance Steel's Deep copy duplicates a drawing style and every sub-style it references, prefixing each copied record's RunName with Copy of or Copy (1), Copy (2), Copy (3), and so on. Use this tool to strip those prefixes or replace them with your own prefix (for example MARK or Marks -) across all style and sub-style tables in one transaction after a pre-change backup snapshot.
