💡 How Cascading Diameters Works

Advance Steel does not store bolt catalogs in a flat list. A functioning bolt diameter requires synchronized entries across 6 distinct database tables:

  1. BoltsDiameters: Registers the nominal diameter in millimeters and the Advance Steel display string.
  2. BoltsDistances: Defines along/across edge distances for hole tolerances (0mm, 1mm, 2mm).
  3. ScrewNew: Sets up the grip-length calculation formulas for each assembly standard (MuS, Mu2S, MuKS).
  4. SetOfBolts: Tells Advance Steel which nuts and washers to package with this bolt diameter.
  5. SetNutsBolts: Creates the actual nut and washer part numbers for this diameter.
  6. SetBolts: Generates the full length run for this diameter with proportional head heights, diameters, and weights.
